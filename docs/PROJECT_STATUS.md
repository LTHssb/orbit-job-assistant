# ORBIT 项目状态

更新时间：2026-09-17

## 已完成

- 银河幕布首页与侧边栏工作台整合。
- 岗位聚合、详情卡片、公司/城市/关键词筛选。
- 招聘来源登记与个人来源列表。
- 静态官网采集与动态官网浏览器采集的双通道架构。
- 每日 09:00（北京时间）自动触发来源采集。
- 采集运行记录、成功/失败状态和岗位数量回写。
- 简历上传、AI 解析入口与结果展示工作流。
- Supabase Auth、用户数据隔离和 Vercel 生产部署。
- 独立公网演示地址：<https://orbit-job-assistant.vercel.app/>

## 已知限制

- 部分招聘官网存在登录、验证码、地区限制或反爬策略，动态采集需要站点级维护。
- 生产环境的每日任务需要持续观察下一轮动态站点运行记录。
- AI 解析属于辅助建议，不能替代用户对简历和职位原文的确认。
- 当前演示数据与真实来源数据并存，需要在正式运营前增加数据新鲜度标识和过期归档策略。

## 首次测试验收

1. 登录后进入 `/jobs`，筛选并打开职位详情。
2. 进入 `/sources`，确认来源列表和采集状态可见。
3. 上传一份 PDF 简历，确认出现解析中、成功或可重试状态。
4. 在 Supabase 检查 `collection_runs`，确认每日任务有运行记录。
5. 在 Vercel 检查 Cron 与函数日志，确认失败时能定位到具体来源。
