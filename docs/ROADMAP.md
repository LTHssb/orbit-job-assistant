# ORBIT 产品路线图

## P0 · 公网可用性

- 完成 Vercel Production 环境变量配置并保持密钥仅在服务端。
- 完成 Supabase 迁移、RLS 与 Auth 验收。
- 验证每日采集任务和动态来源的完整运行链路。
- 简历解析失败时提供明确状态、重试入口和原文回退。

## P1 · 数据质量

- 为百度、字节、腾讯等主要站点建立独立适配器测试样例。
- 增加岗位去重、过期岗位归档、来源健康度和数据新鲜度标签。
- 为每个字段记录“官网原文 / 模型抽取 / 人工修订”来源。

## P2 · 求职效率

- 增加岗位收藏、投递状态和提醒。
- 增加 JD 与简历的匹配解释和可编辑优化建议。
- 增加岗位变更通知、订阅偏好和周报。
